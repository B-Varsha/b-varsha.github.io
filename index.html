Projects

Innovative solutions combining machine learning, data science, and software engineering

Facial Anti-Spoofing System

The project involves developing a facial anti-spoofing system powered by Vision Transformer architectures. By introducing cross-layer relation modeling and multi-scale feature fusion, it enhances robustness against spoofing attempts under varied lighting and pose conditions. Real-time deployment is achieved through a Flask-based interface with WebRTC-enabled client-server communication for live image validation.

Vision Transformers Computer Vision Flask WebRTC

Background Removal using PCA

In this project, Principal Component Analysis (PCA) is used as a dimensionality reduction tool for isolating foreground from background. By extracting essential components, PCA enhances clarity, focusing on main elements and reducing background noise for improved visual quality.

PCA Dimensionality Reduction Image Processing Machine Learning

Airline Reservation System

This project facilitates seamless airline reservations through real-time data streaming via Apache Kafka. Uses the analytical power of Apache Spark and Spark SQL to extract valuable insights from reservation data. Enhances efficiency and precision in managing airline bookings for an optimized customer experience.

Apache Kafka Apache Spark Real-time Streaming Data Analytics

Immunization Effectiveness in Rural Areas

This project employs machine learning regression models to analyze demographic, clinical, and genomic data, predicting childhood immunization likelihood among Indian women. It addresses regional variations, including urban, hilly, and rural areas, aiming to enhance vaccine coverage and personalize strategies for vulnerable populations.

Machine Learning Regression Models Healthcare Analytics Data Science

PennyWise - Expense Management System

PennyWise is a web application streamlining bill splitting. With a user-friendly interface, it allows easy receipt uploading, item selection, and precise cost calculation, offering an efficient tool for groups managing shared expenses.

Web Development JavaScript UI/UX Design Financial Tech
